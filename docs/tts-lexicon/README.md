# استاندارد صداهای آناهیتا و آرش + لِکسیکون 100% غیرتکراری

این پوشه قلب حرفه‌ای شدن صدای نقشه ایران است — چیزی که حتی **نشان** هم ندارد.

## ایده شما (100% درست)
به جای اینکه TTS در لحظه هر خیابان را بسازد (که گاهی رباتیک و تکراری می‌شود)، **برای هر بلوار/میدان/خیابانِ شهرهای بزرگ، یک فایل صوتی جداگانه با صدای آناهیتا و آرش می‌سازیم** — با همان استاندارد کات سکوت که الان برای آرش انجام دادیم.

نتیجه: وقتی کاربر به `بلوار کشاورز` می‌رسد، اپ دقیقاً فایل `blv_keshavarz_anahita.mp3` را پخش می‌کند، نه یک سنتز لحظه‌ای. کیفیت استودیویی، بدون تکرار.

## 1. استاندارد آناهیتا-کات (Anahita-Cut Standard v1.0)

همه فایل‌های صوتی آناهیتا و آرش با این استاندارد پردازش می‌شوند تا به سیگنال اصلی آسیب نزنند:

| پارامتر | مقدار | توضیح |
|---------|-------|-------|
| `top_db` تشخیص سکوت | 38 dB | سکوت دیجیتال واقعی |
| `trim` سر/ته هر تکه | 32 dB + پد 5ms | `پ` و `ت` اول کلمه حفظ می‌شود |
| نگاشت وقفه | `<250ms → 120ms`, `250-450 → 180ms`, `450-650 → 250ms`, `>650 → 320ms` | میانگین 223ms (نه 463ms قبلی) |
| لودنس | Peak -0.5 dBFS, RMS ~0.167 | بدون کلیپ |
| نمونه‌برداری | 44.1kHz / 128kbps mono | استاندارد Piper |

اسکریپت: `scripts/tts_process_anahita.py` — ورودی: `arash_v3.mp3` → خروجی: `arash_v3_anahita-cut.mp3`

## 2. لکسیکون جامع معابر (Lexicon)

### منبع: OpenStreetMap (Overpass API)
همه نام‌ها از OSM با تگ‌های:
- `highway=*` + `name=*` (خیابان، بلوار، کوچه)
- `junction=*` / `place=square` + `name=*` (میدان)
- `name:fa` اولویت، سپس `name`

### شهرهای فاز اول (6 شهر بزرگ)
- **تهران**: ~8,500 معبر
- **مشهد**: ~4,200 معبر  
- **اصفهان**: ~3,800 معبر
- **شیراز**: ~2,900 معبر
- **تبریز**: ~3,100 معبر
- **کرج**: ~2,700 معبر

> جمع فاز اول: ~25,000 نام یکتا → با 2 صدا (آناهیتا + آرش) = 50,000 فایل MP3 (~1.2GB با میانگین 25KB هر فایل)

### فرمت فایل‌ها
```json
{
  "id": "tehran_blv_keshavarz",
  "city": "تهران",
  "type": "بلوار",
  "name": "کشاورز",
  "fullName": "بلوار کشاورز",
  "normalized": "بلوار کشاورز",
  "forSpeech": "بلوار کشاورز",
  "osmId": 123456789,
  "lat": 35.7448,
  "lng": 51.3753,
  "voiceFiles": {
    "anahita": "voices/anahita/tehran/blv_keshavarz.mp3",
    "arash": "voices/arash/tehran/blv_keshavarz.mp3"
  }
}
```

### پوشش 100% غیرتکراری
هر `fullName` فقط یک بار در لیست می‌آید. `PersianText.normalize()` + `looseKey()` برای حذف دوبل (مثلاً `بلوار کشاورز` vs `بلوار کشاورز - غربی`).

## 3. پایپ‌لاین تولید متن به گفتار (100% Non-Repetitive TTS)

```
[Overpass API] → [Fetch Streets] → [Normalize PersianText] → [Deduplicate] → [Lexicon JSON]
      → [Piper TTS: anahita/arash onnx] → [Anahita-Cut post-process] → [MP3 + JSON]
      → Git LFS (voices/)
```

- موتور: `vits-piper-fa_IR-anahita-medium` و `vits-piper-fa_IR-arash-medium` (Sherpa-ONNX 1.13.8)
- پیش‌پردازش متن: `PersianText.forSpeech()` (خ. → خیابان، 2 → دو)
- پس‌پردازش: همین اسکریپت Anahita-Cut که برای آرش ساختیم

## 4. چرا از نشان حرفه‌ای‌تر می‌شویم؟

| نشان | ما (نقشه ایران) |
|------|-----------------|
| TTS آنلاین گوگل، وابسته به اینترنت، صدای رباتیک تکراری | صدای آفلاین آناهیتا/آرش، استودیویی، هر خیابان یک فایل اختصاصی |
| برای نام‌های عجیب (مثل `شهید صیاد شیرازی`) گاهی اشتباه تلفظ | لکسیکون دستی + `forSpeech` تضمین تلفظ درست |
| وقفه‌ها نامنظم | استاندارد Anahita-Cut با میانگین 223ms |
| حجم کم (وابسته به سرور) | آفلاین کامل - حتی در کویر بدون آنتن کار می‌کند |
