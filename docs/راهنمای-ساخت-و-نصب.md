## ۲) گام ۰ — باز کردن پروژه

ZIP را در مسیری **بدون فاصله و حروف فارسی** باز کنید، مثلاً `C:\dev\IranAmap` یا `~/dev/IranAmap`، سپس در Android Studio: `File ▸ Open` → پوشه‌ی `IranAmap` (نه `app`).

## ۳) گام ۱ — مسیر SDK

`local.properties.example` را به `local.properties` تغییر نام دهید:

```properties
sdk.dir=C:/Users/YourName/AppData/Local/Android/Sdk
# لینوکس: sdk.dir=/home/yourname/Android/Sdk
# مک:     sdk.dir=/Users/yourname/Library/Android/sdk
```

در Android Studio: `Settings ▸ Languages & Frameworks ▸ Android SDK` → نصب **Android 14 (API 34)** و **Build-Tools 34**.

## ۴) گام ۲ — موتور صدای sherpa-onnx

```bash
./scripts/fetch_models.sh          # لینوکس/مک
bash scripts/fetch_models.sh       # ویندوز (Git Bash)
```

یا دستی: دانلود
`https://github.com/k2-fsa/sherpa-onnx/releases/download/v1.13.8/sherpa-onnx-1.13.8.aar`
و گذاشتن با نام دقیق **`sherpa-onnx.aar`** در **`app/libs/`**.

ساختار مورد انتظار مدل همراه:

```
app/src/main/assets/tts/vits-piper-fa_IR-amir-medium-int8/
├── fa_IR-amir-medium.onnx      (۱۸ مگ)
├── tokens.txt
└── espeak-ng-data/
```

## ۵) گام ۳ — ساخت

```bash
./scripts/build_apk.sh            # debug → app/build/outputs/apk/debug/app-debug.apk
./scripts/build_apk.sh release    # release (unsigned)
# یا
./gradlew --no-daemon assembleDebug
```

## ۶) گام ۴ — نصب

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

یا فایل APK را به گوشی منتقل و مستقیم نصب کنید.

## ۷) گام ۵ — اولین اجرا

1. مجوز **موقعیت** و **اعلان** را بدهید.
2. ۵ تا ۱۵ ثانیه صبر کنید تا مدل صوتی از assets استخراج شود؛ سپس `تنظیمات ▸ صدا ▸ آزمایش صدا`.
3. برای آفلاین: `تنظیمات ▸ نقشه‌های آفلاین` → استان → شهر → دکمه‌ی دانلود (هیچ دانلود خودکاری نیست).
4. ناوبری: جست‌وجو (یا دسته‌بندی) → انتخاب مقصد → «شروع ناوبری».

## ۹) عیب‌یابی

| مشکل | راه‌حل |
|---|---|
| `SDK location not found` | `local.properties` بسازید (گام ۱) |
| `Unsupported class file major version` | JDK 17 را در `Settings ▸ Build ▸ Gradle ▸ Gradle JDK` انتخاب کنید |
| `OutOfMemoryError` | `-Xmx1536m`، `./gradlew --stop`، بستن مرورگر |
| `Could not find sherpa-onnx.aar` | گام ۲ انجام نشده |
| نقشه خالی است | اینترنت لازم است (OpenFreeMap) مگر شهر را دانلود کرده باشید |
| صدا پخش نمی‌شود | آزمایش صدا، بلندی رسانه، صبر برای استخراج مدل، لاگ‌کت با تگ `SherpaTts` |
| شمارش چراغ نمی‌آید | فقط هنگام ناوبری و اگر چراغ OSM تا ۲.۵ کیلومتر جلوتر باشد؛ تهران/مشهد/اصفهان بهترین نمونه‌اند |
| دوربین سرعت کم پیدا می‌شود | داده‌ی OSM ایران در این زمینه ناقص است؛ در کلان‌شهرها بهتر است |
| `INSTALL_FAILED_UPDATE_INCOMPATIBLE` | `adb uninstall com.iranamap.real` سپس نصب مجدد |

## ۱۰) امضا برای انتشار

```bash
keytool -genkeypair -v -keystore iranamap-release.jks -alias iranamap -keyalg RSA -keysize 2048 -validity 10000
```

سپس در `app/build.gradle.kts`:

```kotlin
signingConfigs {
    create("release") {
        storeFile = file("../iranamap-release.jks")
        storePassword = System.getenv("IRANAMAP_STORE_PASSWORD")
        keyAlias = "iranamap"
        keyPassword = System.getenv("IRANAMAP_KEY_PASSWORD")
    }
}
buildTypes { release { signingConfig = signingConfigs.getByName("release") } }
```

```bash
./gradlew --no-daemon assembleRelease
```
