# آپلود در گیت‌هاب و ساخت APK — راهنمای عملی (۳ تا ۵ دقیقه)

> **نکته‌ی امنیتی اول:** رمز حساب گیت‌هاب را هرگز در چت، ایمیل یا فایل نگذارید. گیت‌هاب از سال ۲۰۲۱ ورود با «رمز» برای عملیات Git را غیرفعال کرده و فقط **توکن** می‌پذیرد. اگر رمزی جایی وارد کرده‌اید، همین حالا:
> 1. `github.com → Settings → Password and authentication → Change password`
> 2. `Settings → Sessions → Sign out of all sessions`
> 3. `Settings → Password and authentication → Two-factor authentication` را روشن کنید.

دو روش دارید. **روش الف ساده‌تر است** و به هیچ نصب و توکنی نیاز ندارد.

---

## روش الف — آپلود با مرورگر (بدون نصب چیزی) ⭐

### گام ۱: مخزن بسازید
1. وارد `github.com` شوید.
2. بالا-راست: دکمه‌ی **`+`** → **`New repository`**.
3. نام: **`iranamap`**
4. `Public` یا `Private` (هر دو رایگان‌اند)
5. گزینه‌های `Add a README file` / `.gitignore` / `license` را **تیک نزنید**.
6. **`Create repository`**.

### گام ۲: فایل‌ها را آپلود کنید
1. در صفحه‌ی مخزن خالی، لینک **`uploading an existing file`** را بزنید (یا `Add file ▸ Upload files`).
2. زیپ `IranAmap-3.1-fa-source.zip` را **روی رایانه باز کنید** و **محتویات** پوشه‌ی `IranAmap` را (نه خودِ پوشه) با ماوس بکشید و در کادر رها کنید.
   - فایل‌ها باید مستقیماً در ریشه باشند: `build.gradle.kts`, `app/`, `gradle/`, `settings.gradle.kts` …
3. پایین صفحه، دکمه‌ی سبز **`Commit changes`**.
4. صبر کنید (~۲ مگابایت مدل صوتی است؛ معمولاً کمتر از ۱ دقیقه).

### گام ۳: پوشه‌ی `.github` (مهم‌ترین نکته)
پوشه‌هایی که با نقطه شروع می‌شوند در ویندوز/مک **مخفی** هستند و ممکن است آپلود نشوند. اگر فایل workflow آپلود نشد:

1. در گیت‌هاب: `Add file ▸ Create new file`
2. در کادر نام فایل، دقیقاً این را بنویسید (با اسلش‌ها):
   ```
   .github/workflows/build-apk.yml
   ```
3. محتوای فایل `IranAmap/.github/workflows/build-apk.yml` را از پروژه باز کنید و در کادر بزرگ پیست کنید.
4. `Commit changes`.

> در ویندوز برای دیدن پوشه‌ی مخفی: پنجره‌ی Explorer → تب `View` → `Show` → `Hidden items`.
> در مک: `Cmd + Shift + .`

### گام ۴: ساخت را اجرا کنید
1. تب **`Actions`** (بالای صفحه).
2. اگر پیامی مثل «Workflows aren’t being run on this repository» دیدید، دکمه‌ی **`I understand my workflows, go ahead and enable them`** را بزنید.
3. ستون چپ: **«ساخت APK»** را انتخاب کنید.
4. دکمه‌ی **`Run workflow ▾`** (سمت راست):
   - **نام بسته:** `ir.shoma.naghshe` (یا هر نام دیگری که انتخاب کرده‌اید)
   - **نوع ساخت:** `debug`
5. **`Run workflow`** را بزنید.

### گام ۵: صبر و دانلود
1. صفحه را نوسازی کنید؛ یک ردیف زرد/سبز با عنوان اجرای شما ظاهر می‌شود → روی آن کلیک کنید.
2. مراحل زنده اجرا می‌شوند:
   `دریافت کد` → `JDK 17` → `Android SDK` → `آماده‌سازی موتور صدا` → `اعتبارسنجی` → `آزمون‌ها (۱۱۴)` → `ساخت APK` → `بارگذاری`
3. زمان: **۵ تا ۱۰ دقیقه** (بار اول). اگر همه‌ی مراحل ✔ سبز شدند:
4. پایین صفحه‌ی اجرا، بخش **`Artifacts`**:
   **`IranAmap-APK`** → کلیک → یک ZIP دانلود می‌شود → باز کنید → **`app-debug.apk`**.
5. APK را به گوشی منتقل و نصب کنید (اجازه‌ی «نصب از منابع ناشناس»).

## روش ب — با Git و توکن (برای افراد آشنا به خط فرمان)

### ۱) توکن بسازید (نه رمز!)
`github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token`

| فیلد | مقدار |
|---|---|
| Token name | `iranamap-upload` |
| Expiration | ۷ روز (کوتاه‌ترین کافی) |
| Repository access | `Only select repositories` → `iranamap` |
| Permissions → Repository permissions → **Contents** | **Read and write** |

سپس توکن را در متغیر محیطی بگذارید (هرگز داخل فایل نگذارید):

```bash
export GH_TOKEN=github_pat_xxxxxxxxxxxxxxxx
```

### ۲) آپلود با اسکریپت آماده
```bash
cd IranAmap
./scripts/push_to_github.sh https://github.com/<username>/iranamap.git
```

اسکریپت این کارها را می‌کند:
- `.gitignore` می‌سازد تا **کلید امضا (`*.jks`)، `local.properties` و `sherpa-onnx.aar`** آپلود نشوند
- مطمئن می‌شود `.github/workflows/build-apk.yml` وجود دارد
- کامیت می‌سازد، توکن را **فقط در همان لحظه** به آدرس push اضافه می‌کند و بعد آدرس را پاک‌سازی می‌کند (توکن در `.git/config` ذخیره نمی‌شود)

خروجی آزمایش‌شده:
```
✔ .gitignore حساس‌ها را مستثنی می‌کند
✔ فایل workflow ساخت APK موجود است
✔ کامیت ساخته شد  (۳۹۵ فایل)
✔ آدرس راه دور پاک‌سازی شد (توکن جایی ذخیره نشد)
✔ پروژه به گیت‌هاب ارسال شد.
```

### ۳) یا فقط با دو دستور خودتان
```bash
git init -b main && git add -A && git commit -m "IranAmap 3.1"
git remote add origin https://github.com/<username>/iranamap.git
git push -u origin main       # نام کاربری: username · رمز: همان توکن
```
> در پنجره‌ی رمز، **توکن** را وارد کنید، نه رمز حساب را.

## پس از ارسال: چه چیزی را چطور بررسی کنید

| موضوع | کجا |
|---|---|
| نتیجه‌ی ۱۱۴ آزمون | Actions → اجرای شما → مرحله‌ی `آزمون‌های واحد` |
| متن خطا (اگر ساخت شکست خورد) | همان مرحله را باز کنید؛ خطوط قرمز آخر مهم‌اند |
| دانلود APK | پایین صفحه‌ی اجرا → `Artifacts` |
| ساخت خودکار بعدی | با هر `push` روی `main` هم خودکار ساخته می‌شود |
| ماندگاری APK | ۳۰ روز (در فایل workflow قابل تغییر) |

## عیب‌یابی سریع

| نشانه | علت | راه‌حل |
|---|---|---|
| تب Actions خالی / هیچ workflow | `.github/workflows/build-apk.yml` آپلود نشده | گام ۳ |
| `No such file or directory: gradlew` | ساختار پوشه اشتباه آپلود شده (`IranAmap/IranAmap/…`) | محتویات پوشه را آپلود کنید، نه خود پوشه را |
| `Permission denied: ./gradlew` | مجوز اجرا | در workflow هست؛ اگر محلی است: `chmod +x gradlew` |
| `Could not find sherpa-onnx.aar` | دانلود در runner ناموفق | `.aar` را دستی در `app/libs/` مخزن بگذارید |
| `SDK location not found` | step نصب SDK حذف شده | `android-actions/setup-android@v3` را برگردانید |
| آزمون شکست خورد | واقعاً مشکلی در کد/منابع | Artifact `test-reports` را دانلود کنید |
| APK نصب نمی‌شود (`UPDATE_INCOMPATIBLE`) | نسخه‌ی قبلی با امضای دیگر | برنامه‌ی قبلی را حذف کنید |

## پرسش «می‌شود خودت آپلود کنی؟»

بله از نظر فنی ممکن است، اما **رمز حساب را نباید به اشتراک گذاشت** — چه با من، چه با هر ابزار دیگری. اگر واقعاً می‌خواهید این کار به‌جای شما انجام شود، تنها روش قابل قبول این است:

1. یک **توکن Fine-grained** بسازید که فقط به همان یک مخزن دسترسی **Contents: write** دارد و **۱ روز** اعتبار دارد.
2. پس از پایان کار، همان توکن را در `Settings → Developer settings → Tokens` **Revoke** کنید.
3. حتی در این حالت بهتر است توکن را در متغیر محیطی بدهید و بعد از استفاده پاک کنید.

اما پیشنهاد جدی من **روش الف** است: چهار کلیک در مرورگر، بدون هیچ توکن و ریسکی — و همان نتیجه را می‌دهد.
