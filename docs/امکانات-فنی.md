# مستند فنی — نقشه ایران ۳.۰

برای توسعه‌دهنده: هر قابلیت کجاست، چطور کار می‌کند و در نخستین کامپایل کجا را بازبینی کنید.

## ۱) معماری

```
MapActivity ── MapView (MapLibre 11.8 · OpenFreeMap)
   │            └─ MapController: مسیر، مسیر جایگزین، مقصد، چراغ، دوربین، POI، کاربر، ساختمان ۳بعدی، برچسب فارسی
   │
   ├─ SearchActivity ── SearchRepository (Nominatim) + PoiRepository (Overpass، ۲۸ دسته)
   ├─ FavoritesActivity ── FavoritesRepository (DataStore + Gson)
   ├─ SettingsActivity / VoiceSettingsActivity / CityDownloadActivity
   │
   ├─ RouteRepository (OSRM، تا ۳ مسیر) → ActiveRoute
   │     └─ RouteTracker → TrackerState → NavStateMapper → NavState
   │                                                    └─ SpeechPlanner → Announcer → SherpaSpeechEngine
   │
   ├─ TrafficLightRepository (Overpass) → TrafficLightModel (چرخه/پیش‌بینی)
   ├─ CameraRepository (Overpass) → SpeedModel (حد مجاز، هشدار، ترافیک تخمینی)
   └─ OfflineRepository (MapLibre OfflineManager، بسته‌بندی قانونی)
```

**اصل:** هر تصمیم خالص در `core/` و `nav/` است و هیچ وابستگی به اندروید ندارد؛ به همین دلیل ۱۱۴ آزمون JUnit روی JVM اجرا می‌شود.

## ۲) فارسی‌سازی

| موضوع | پیاده‌سازی |
|---|---|
| زبان | `LocaleManager.applyPersian` + `AppCompatDelegate.setApplicationLocales("fa-IR")`، `resourceConfigurations += "fa"` |
| RTL | `supportsRtl=true`، چیدمان‌های start/end |
| فونت | `res/font/vazirmatn_{regular,medium,bold}.ttf` روی تم |
| اعداد/تاریخ | `PersianText.toPersianDigits`، `JalaliDate`، `PersianText.jalaliShort` |
| گفتار | `PersianText.numberToWords`، `digitsToWords`، `formatDistanceSpeech` |
| جست‌وجو | `PersianText.normalize` (ی/ي، ک/ك، اعراب) |
| برچسب نقشه | `MapController.applyPersianLabels` → `text-field = coalesce(name:fa, name, name:nonlatin)` |

**تأییدشده با درخواست واقعی:** تایل‌های OpenFreeMap ایران فیلد `name:fa` دارند و فونت‌استک `Noto Sans Regular` شامل `Noto Naskh Arabic` است (بازه‌ی `1536-1791` سرو می‌شود) — پس برچسب فارسی بدون فونت محلی رندر می‌شود.

## ۳) ناوبری سه‌بعدی

| مرحله | فایل |
|---|---|
| چند مسیر | `RouteRepository.fetchRoutes` (`alternatives=true`، مرتب بر اساس زمان) |
| پیگیری | `RouteTracker.update` → `TrackerState` (فاصله تا مانور، انحراف، مسافت باقی‌مانده) |
| وضعیت صوتی | `NavStateMapper.toNavState` → `SpeechPlanner.onNavigation` |
| نمایش | `ManeuverText.glyph/shortPhrase` + `LanePlanner.plan` + `LaneGuidanceView` |
| دوربین | `MapController.followPosition` (tilt 60°, bearing حرکت, zoom 17) |
| ساختمان ۳بعدی | لایه‌ی `building-3d` اگر بود، وگرنه `FillExtrusionLayer` با `coalesce(render_height, height, 12)` |
| بازمحاسبه | انحراف > ۵۵ متر → `reroute()` |
| پس‌زمینه | `NavigationService` (FGS نوع location) |

## ۴) چراغ راهنمایی

1. کشف: `TrafficLightRepository.lightsAround` (Overpass `highway=traffic_signals`, شعاع ۲.۵km، کش ۱۰ دقیقه‌ای، بازپرس‌وجو هر ۴۰۰ متر).
2. مدل: `TrafficLightModel.seedFor(lat,lng,id)` → `timingFor(seed, arterial)` (چرخه‌ی سبز/زرد/قرمز + آفست، متصل به ساعت روز → تکرارپذیر و همگام).
3. پیش‌بینی رسیدن: `forecastAtArrival(timing, secondsOfDay, travelSec)`.
4. نمایش: `showLights` (سه لایه: هاله/بدنه + رنگ از ویژگی `color`) و کارت شمارش معکوس؛ تیکر یک‌ثانیه‌ای.
5. گفتار: `SpeechPlanner.onLights` (آستانه‌ی فاصله بر اساس پرحرفی، کول‌داون ۲۵ ثانیه، کلید یکتا برای هر چراغ).
6. یادگیری: `TrafficLightLearner.inferCycleSeconds/inferTiming` آماده است اما فعلاً تغذیه نمی‌شود → پیش‌بینی «تخمینی» است و در متن هم همین گفته می‌شود.

## ۵) دوربین سرعت و محدودیت

- `SpeedModel.parseMaxspeed`: عدد، `km/h`، `mph`، `walk`، `none`، و مقادیر کشوری `IR:urban=50` / `IR:rural=85` / `IR:trunk=100` / `IR:motorway=120`.
- `CameraRepository.camerasAround`: `highway=speed_camera` + `enforcement=maxspeed|red_light|average` (شعاع ۴km، کش ۱۰ دقیقه).
- هشدار: `cameraWarningDistanceMeters = سرعت × ۶` (۲۵۰–۹۰۰ متر)؛ گفتار با `SpeedModel.cameraSpeech`.
- عبور از حد: `isOverLimit(kmh, limit, 5)` با کول‌داون ۳۰ ثانیه در `SpeechPlanner.onSpeedAndCameras`.
- ترافیک: `SpeedModel.trafficFactor(roadClass, secondsOfDay)` (۰.۸–۱.۸) روی ETA اعمال می‌شود — **تخمینی**، نه داده‌ی زنده.

## ۶) کشف مکان

- `Categories.all` (۲۸ دسته) هر یک با `overpassFilter`، `textQuery` و `glyph`.
- `Categories.overpassQuery` رشته‌ی Overpass می‌سازد (شعاع محدود ۱۰۰–۲۰۰۰۰ متر، `out center`).
- `PoiRepository.byCategory`: Overpass اول؛ اگر خالی بود، جست‌وجوی متنی Nominatim به‌عنوان جایگزین.
- `SearchActivity`: چیپ‌های دسته + جست‌وجوی متنی؛ نتایج با `PlaceAdapter`؛ بازگشت با `setResult` به نقشه.
- نمایش روی نقشه: `MapActivity.showPoisOnMap` + `MapActivity.pendingPois`؛ ضربه روی نشانگر → دیالوگ «مسیریابی / ذخیره / اشتراک».

## ۸) نقشه‌ی آفلاین

- `CityCatalog`: ۲۹۲ شهر / ۳۱ استان.
- `OfflinePlanner`: سقف هر بسته **۱۱۰۰ کاشی** و **۴۵ مگابایت**.
- `OfflineRepository`: `setOfflineMapboxTileCountLimit(2_000_000)`، `createOfflineRegion` + `OfflineRegionObserver`، دانلود **پشت‌سرهم** بسته‌ها.
- `CityDownloadActivity`: جست‌وجو، چیپ استان، حجم مصرفی، تأیید شهر بزرگ، حذف. **هیچ دانلود خودکاری وجود ندارد.**

## ۱۰) نقاط بازبینی در نخستین کامپایل

این پروژه در محیطی بدون Android SDK نوشته شده؛ فقط `core` و `nav` با `kotlinc` کامپایل و آزمایش شده‌اند. در نخستین `assembleDebug` این نقاط را اول ببینید:

1. **MaterialSwitch** (`com.google.android.material.materialswitch.MaterialSwitch`) نیاز به Material 1.7+ دارد؛ پروژه روی 1.12 است. اگر خطا داد، به `SwitchMaterial` ساده تغییر دهید.
2. **APIهای MapLibre** با `javap` روی `android-sdk:11.8.0` تأیید شده‌اند (`OfflineRegionObserver.mapboxTileCountLimitExceeded` در این نسخه نام قدیمی دارد).
3. **sherpa-onnx**: امضای `OfflineTts.generateWithCallback(text, sid, speed, callback)` مطابق 1.13.8 است؛ اگر نسخه‌ی AAR را عوض کردید `tts/SherpaSpeechEngine.kt` را بازبینی کنید.
4. **`PendingIntent`/FGS**: مجوزهای `FOREGROUND_SERVICE_LOCATION` و `POST_NOTIFICATIONS` در اولین اجرا گرفته می‌شوند؛ اگر رد شوند ناوبری داخل برنامه ادامه می‌یابد.
5. **صدا در شبیه‌ساز**: `ENCODING_PCM_FLOAT` روی شبیه‌ساز روان نیست؛ روی گوشی واقعی آزمایش کنید.
6. **داده‌ی OSM ایران**: چراغ و دوربین در کلان‌شهرها بهتر است؛ در شهرهای کوچک ممکن است چیزی پیدا نشود (این طبیعی است، نه باگ).

## ۱۱) کارهای پیشنهادی بعدی

- کالیبراسیون چرخه‌ی چراغ با مشاهده‌های واقعی (`TrafficLightLearner` آماده است).
- کش محلی نام خیابان‌ها برای کاهش درخواست Nominatim.
- تشخیص گفتار فارسی (ASR) با sherpa-onnx برای دستیار صوتی ورودی.
- مسیر چندمرحله‌ای (چند مقصد) و مسیر پیاده/دوچرخه.
