# نقشه ایران — IranAmap ۳.۳ (نسخه‌ی فارسی)


> آخرین بسته‌ی قابل نصب و وضعیت ساخت را در تب **Actions** مخزن ببینید؛ بسته‌های قدیمی ممکن است تغییرات جدید را نداشته باشند. آزمایش روی گوشی واقعی همچنان ضروری است.

بازسازی کامل برنامه‌ی نقشه برای ایران، با مرجع‌گیری از **آمپ واقعی ۱۷.۰۱.۰.۲۰۱۲** که کاربر فراهم کرد.
تمرکز: **مسیریابی سه‌بعدی**، **چراغ‌های راهنمایی هوشمند**، **دستیار صوتی فارسی مستقل از TTS اندروید** و **نقشه‌ی آفلاین انتخابی**.

| | |
|---|---|
| نام بسته | `com.iranamap.real` |
| نسخه | `3.3.0-fa` (versionCode 33) |
| زبان | فارسی، RTL، اعداد و تاریخ شمسی، فونت وزیرمتن |

## شروع سریع

### اگر رایانه‌ی قوی دارید (محلی)
```bash
./scripts/set_package_name.sh ir.shoma.naghshe  # نام بسته‌ی خودتان
./scripts/fetch_models.sh                       # موتور sherpa-onnx
cp local.properties.example local.properties    # سپس sdk.dir را بنویسید
./scripts/build_apk.sh                          # → app/build/outputs/apk/debug/app-debug.apk
./scripts/test_all.sh                           # اعتبارسنجی + آزمون‌های واحد
```


## امکانات

- **ناوبری سه‌بعدی:** دوربین ۶۰°، ساختمان‌های سه‌بعدی با ارتفاع OSM، راهنمای خطوط، پنل مانور، بازمحاسبه‌ی خودکار، مسیرهای جایگزین.
- **چراغ راهنمایی:** موقعیت چراغ‌های OSM در صورت موجود بودن نمایش داده می‌شود. رنگ و زمان واقعی از OSM در دسترس نیست؛ برنامه وضعیت را «نامشخص» نشان می‌دهد. همواره از چراغ واقعی پیروی کنید.
- **دوربین و سرعت:** دوربین `speed_camera`/`enforcement` در صورت وجود داده‌ی OSM نمایش داده می‌شود. حد سرعت فقط در صورت داشتن داده‌ی صریح نشان داده می‌شود و جایگزین تابلوهای راه نیست.
- **کشف مکان:** ۲۸ دسته‌ی OSM (بنزین، CNG، پارکینگ، شارژ، بیمارستان، داروخانه، رستوران، هتل، مترو، مسجد…) + جست‌وجوی متنی فارسی.
- **ذخیره‌ها:** خانه/کار/دلخواه + تاریخچه‌ی مقصدها + اشتراک‌گذاری.
- **صدا:** ۶ گوینده‌ی فارسی، سرعت/بلندی/نوع اعلام، سه سطح پرحرفی — بدون هیچ وابستگی به سرویس‌های گوگل.
- **آفلاین:** ۲۹۲ شهر / ۳۱ استان، دانلود فقط با انتخاب کاربر، بسته‌های ≤۱۱۰۰ کاشی و ≤۴۵ مگابایت.

## وضعیت بررسی

نتیجه‌ی هر تغییر در GitHub Actions ثبت می‌شود: اعتبارسنجی ایستا، آزمون‌های واحد و ساخت APK؛ گردش کار جداگانه‌ای نیز سناریوهای اصلی را روی شبیه‌ساز اندروید اجرا می‌کند. موفقیت شبیه‌ساز جایگزین تست Redmi 10C نیست.

## ساختار

```
app/src/main/java/com/iranamap/real/
├── MapActivity.kt     نقشه، جست‌وجو، ناوبری، چراغ، دوربین، اشتراک‌گذاری
├── core/              منطق خالص و آزمایش‌شده (فارسی، چراغ، سرعت، دسته‌ها، شهرها)
├── data/              OSRM · Nominatim · Overpass · ذخیره‌ها
├── nav/               مدل مسیر، ردیاب، تبدیل وضعیت
├── map/               لایه‌ها، برچسب فارسی، سه‌بعدی، POI، دوربین
├── offline/           نقشه‌ی آفلاین (MapLibre OfflineManager)
├── tts/               sherpa-onnx + صف گفتار + نصب صداها
├── ui/                جست‌وجو، ذخیره‌ها، تنظیمات، صدا، دانلود شهر
└── service/           سرویس پیش‌زمینه‌ی ناوبری
```
